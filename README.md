# Dizzy Visuals 1.21.1

Client-side visual Minecraft mod for **Minecraft 1.21.1 + Fabric**.

## Included effects
- Visual aura
- Player trail
- Teleport particles
- Sparkle particles
- FPS Boost toggle

## Controls
- **V** — visual effects on/off
- **B** — FPS Boost on/off

## Build the JAR automatically on GitHub

This project includes a GitHub Actions workflow. You do **not** need Gradle installed on your phone.

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository.
3. Open the **Actions** tab.
4. Select **Build Dizzy Visuals**.
5. Press **Run workflow**.
6. Wait for the build to finish.
7. Open the completed workflow run and download the artifact named **dizzy-visuals-1.21.1**.
8. Inside the downloaded artifact is `dizzy-visuals-1.0.0.jar`.

The generated JAR goes into Minecraft's `mods` folder together with Fabric API.
